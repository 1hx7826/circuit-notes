# 设计说明

电路手记是一份供电脑与手机随时翻阅的章节式硬件笔记，不设每日任务、积分或强制解锁。

色彩使用纸白 #FFFFFF、冷灰 #F7F9FB、墨蓝 #213748、电路蓝 #176A83 和铜色 #A56431。标题和正文使用本机 Segoe UI / 微软雅黑，课次数字使用 Bahnschrift，数学使用随站点提供的 KaTeX 字体。

桌面布局为固定目录、主阅读区、单课页右侧锚点；首页以两列章节列表呈现课程顺序。手机为单列正文与抽屉目录。视觉识别集中在电路走线标志和简化电路插图，周围保持清晰、安静。

阅读正文不截断，自检与易错点可以快速跳转。公式和长表格在各自容器内滚动，不让主页面横向移动。主题跟随系统，也可手动切换。键盘焦点、原生对话框焦点约束、减少动态效果和大字号均已纳入实现。
